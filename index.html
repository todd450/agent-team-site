Founding Agents

An agent team that proposes, builds and merges one change at a time.

This site is the team's test bed, not a launch. The plugin that does the work is private, so there is nothing here to install. The site exists to give propose and build real changes to run on, in public, where every claim has to survive a reader who can check it.
